## URM37超音波センサの配線

URM37は3.3Vで動作させるため、Echo用の抵抗分圧回路は不要です。

1. **VCC（1番ピン）** → XIAO RP2040の **3V3**
2. **GND（2番ピン）** → XIAO RP2040の **GND**
3. **ECHO（4番ピン）** → XIAO RP2040の **D1**
4. **COMP/TRIG（6番ピン）** → XIAO RP2040の **D0**

以下の端子は、今回の距離測定では接続しません。

- NRST（3番ピン）
- SERVO（5番ピン）
- DAC_OUT（7番ピン）
- RXD（8番ピン）
- TXD（9番ピン）

> 配線のイメージ：  
> `URM37 VCC` → `XIAO 3V3`  
> `URM37 GND` → `XIAO GND`  
> `URM37 ECHO` → `XIAO D1`  
> `URM37 COMP/TRIG` → `XIAO D0`

## microSDカードモジュールの配線

microSDカードモジュールは、端子列の番号に従って接続します。

1. **2番ピン：CD/DAT3（CS）** → XIAO RP2040の **D7**
2. **3番ピン：CMD（MOSI）** → XIAO RP2040の **D10**
3. **4番ピン：VDD** → XIAO RP2040の **3V3**
4. **5番ピン：CLK（SCK）** → XIAO RP2040の **D8**
5. **6番ピン：VSS（GND）** → XIAO RP2040の **GND**
6. **7番ピン：DAT0（MISO）** → XIAO RP2040の **D9**

以下は接続しません。

- 1番ピン：DAT2
- 8番ピン：DAT1
- 9番・10番ピン：カード検出スイッチ

> 注意：microSDモジュールのVDDには、5Vではなく必ずXIAOの3V3を接続します。


### 2. パソコンとつなげてプログラムを書き込む
改良の余地だらけいったん成功しただけのとりあえずのプログラム

```
#include <SPI.h>
#include <SD.h>

const int SD_CS = D7;

const int URM_TRIG = D0;
const int URM_ECHO = D1;

void setup() {
  Serial.begin(115200);
  delay(1000);

  pinMode(URM_TRIG, OUTPUT);
  pinMode(URM_ECHO, INPUT);
  digitalWrite(URM_TRIG, HIGH);

  Serial.println("SDカードを確認中...");

  if (!SD.begin(SD_CS)) {
    Serial.println("SDカードを認識できません");
    while (true) {
      delay(1000);
    }
  }

  Serial.println("SDカードを認識しました");

  File file = SD.open("/distance.csv", FILE_WRITE);
  if (file) {
    if (file.size() == 0) {
      file.println("time_ms,distance_cm");
    }
    file.close();
  }
}

void loop() {
  // URM37へ測定開始を指示
  digitalWrite(URM_TRIG, LOW);
  delayMicroseconds(10);
  digitalWrite(URM_TRIG, HIGH);

  // ECHOのLOWパルス幅を読む（50µs = 1cm）
  unsigned long pulse = pulseIn(URM_ECHO, LOW, 60000);

  if (pulse == 0) {
    Serial.println("測定できません");
  } else {
    unsigned long distanceCm = pulse / 50;
    

    Serial.print("距離: ");
    Serial.print(distanceCm);
    Serial.println(" cm");

    File file = SD.open("/distance.csv", FILE_WRITE);

    if (file) {
      file.print(millis());
      file.print(",");
      file.println(distanceCm);
      file.close();

      Serial.println("SDへ記録しました");
    } else {
      Serial.println("distance.csv を開けません");
    }
  }

  delay(1000);
}
```
